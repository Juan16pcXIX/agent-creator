# Archetypes

Starting points for common roots. Use them to avoid blank-page drafting, then cut, merge and add based on the user's real recurring work. Never ship an archetype as-is.

Models shown are typical results of the routing rubric on a balanced budget.

## Business or brand

Lens: by function.

| Branch | Typical leaves |
|---|---|
| Marketing | content strategist (opus), trend scout (haiku), copywriter / carousel writer (sonnet), video editor brief or script (sonnet), fact-checker (sonnet), scheduler (haiku) |
| Sales | lead researcher (sonnet), outreach writer (sonnet), CRM updater (haiku), proposal builder (sonnet) |
| Finance | bookkeeping categorizer (haiku), cash-flow forecaster (opus), reconciler / verifier (sonnet), pricing analyst (opus) |
| Operations | supplier tracker (haiku), inventory checker (haiku), process documenter (sonnet) |
| Customer support | reply drafter (sonnet), FAQ maintainer (haiku), escalation triager (sonnet) |
| Product | feedback synthesizer (sonnet), roadmap planner (opus) |

## Content creator

Lens: by stage.

| Branch | Typical leaves |
|---|---|
| Ideas | trend scout (haiku), idea ranker (sonnet) |
| Writing | hook writer (sonnet), scriptwriter (sonnet), title and description writer (sonnet) |
| Production | asset finder (haiku), editor brief or edit plan (sonnet), voice or subtitles (haiku) |
| Quality | reviewer against channel rules (opus when the channel's reputation is at stake, else sonnet) |
| Publishing | upload sheet builder (haiku), analytics reader (sonnet) |

## Musician or artist

| Branch | Typical leaves |
|---|---|

## Software product

Lens: by function, with stages inside.

| Branch | Typical leaves |
|---|---|
| Planning | spec writer (opus), ticket splitter (sonnet) |
| Building | implementer per area (sonnet), migration writer (sonnet) |
| Quality | test writer (sonnet), code reviewer (opus), security reviewer (opus) |
| Docs | changelog writer (haiku), docs updater (sonnet) |
| Release | release checklist runner (haiku) |

## Operations or logistics

Lens: by stage, with double review.

| Branch | Typical leaves |
|---|---|
| Intake | document reader and extractor (haiku), data validator (sonnet) |
| Review | first reviewer: quantities, dates, totals (sonnet); second reviewer: parties, addresses, terms (sonnet) |
| Planning | route or schedule planner (opus) |
| Communication | status update writer (sonnet), exception notifier (haiku) |
| Records | filing and naming (haiku), audit log keeper (haiku) |

## Research or academic

Lens: by stage.

| Branch | Typical leaves |
|---|---|
| Discovery | literature searcher (sonnet), source summarizer (haiku) |
| Analysis | data analyst (opus), method critic (opus) |
| Writing | section drafter (sonnet), citation checker (haiku), editor (sonnet) |

## Personal goal

Lens: by outcome. Keep it small: 3 or 4 branches, 2 or 3 leaves each.

Example, "run a marathon in 6 months": training planner (opus), weekly adjuster (sonnet), nutrition planner (sonnet), recovery advisor (sonnet), progress tracker (haiku).

## Custom

If nothing fits, draw the tree from the user's own words: list the verbs they use for their recurring work, group the verbs by who would do them in a real team, and continue with decomposition.md.
